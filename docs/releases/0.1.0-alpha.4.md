# CalMee 0.1.0-alpha.4

## 中文

本次为源码预发布，重点改进会议编辑、刷新一致性及日程关联。

- 会中笔记与文档保存状态更一致；页面切换保留草稿和阅读位置，旧请求不再覆盖较新的页面状态。
- 统一资源更新通知；说话人、会议列表、日历、模型管理和得到导入后更新相关页面。
- 会议与日程采用唯一关联表、事务化关联/解除和明确的转移确认；只读 macOS 日程也可以在 CalMee 内关联。
- 录音、仅保存笔记和放弃音频保留笔记使用统一关联流程；关联失败不撤销已保存内容。
- 自定义 ASR/AI 模型配置、设置布局与录音文件命名改进；得到笔记增加分页、筛选和批量选择。

### 升级与限制

升级前退出应用，备份完整且一致的数据库及重要录音。新增模型配置和日程关联迁移；旧关联冲突会保留待核对，不随意选择归属。降级必须恢复升级前数据库，不能删除迁移记录。

自动验证覆盖前端刷新/导入、日程关联冲突、删除事务回滚和 SQL 迁移；尚未完成所有桌面交互、干净机器及长录音回归。周期日程身份、计划/实际时间分离及跨进程笔记原子写入仍待后续完善。

本次不附公开 DMG：本机开发包的 FFmpeg 仍链接 Homebrew 动态库，且未完成独立分发依赖/许可清单验证。它不能作为干净电脑可用的安装包。没有 Apple Developer ID 签名/公证；本机测试安装采用 ad-hoc 签名。不包含模型、Python 运行环境、数据库、录音或用户配置。

## English

This source-only alpha improves meeting editing, refresh consistency and calendar linking.

- Preserve drafts and reading position across navigation; reject stale asynchronous results and coordinate document saves.
- Share resource-change notifications across meeting, speaker, calendar, model and imported-note views.
- Use a canonical one-to-one calendar link with transactional updates, explicit transfer confirmation and stale-window protection. Local links also work with read-only macOS events.
- Unify calendar attachment for recordings and notes-only meetings; attachment failures do not undo saved content.
- Improve custom ASR/AI profiles, settings, recording filenames, and Dedao pagination/filtering/bulk selection.

Back up a consistent database and important recordings before upgrading. Two new migrations add model profiles and calendar links. Ambiguous legacy claims are retained for review. Downgrading requires the pre-upgrade database; never remove migration records to force a downgrade.

Automated tests do not replace full desktop, clean-machine or long-recording acceptance tests. Recurrence identity, planned versus actual times and atomic cross-process note writes remain follow-up work.

No public DMG is attached: the local development bundle still links FFmpeg against Homebrew libraries, and standalone dependency/license validation is incomplete. It is not a portable installer. There is no Apple Developer ID signing or notarization; local testing uses an ad-hoc signature. No model weights, Python runtime, databases, recordings or user settings are included in this source release.
