# Security Policy

CalMee handles recordings, transcripts, credentials, and potentially sensitive
meeting content. Please do not disclose a vulnerability in a public issue.

Until a dedicated security contact is published, report a suspected vulnerability
through a private GitHub security advisory in the CalMee repository. Include the
affected version, reproduction steps, impact, and any suggested mitigation.

The pre-release source has no guaranteed response time. Supported versions and a
security contact will be listed here before the first stable release.

Never include real recordings, API keys, passwords, tokens, or personal data in a
report. Use a minimal synthetic example.
