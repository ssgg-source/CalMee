# CalMee Privacy Policy

Last updated: 2026-08-10

## 1. Local data

CalMee stores recordings, transcripts, meeting records, AI meeting notes, people, voiceprints, hotwords, model settings, and calendar links on the device by default. Installing or launching CalMee does not automatically upload this data.

## 2. Local models

FunASR and local language models run on the device. The CalMee installer does not include FunASR model weights. A model is downloaded from the selected model platform only after the user chooses it. The platform may log normal network request data under its own privacy policy.

## 3. Cloud language models

When a user configures and invokes a cloud model, CalMee sends the meeting text, prompts, and settings required for the selected task to that provider. API keys are stored in local application data. Users are responsible for reviewing each provider's retention, training, cross-border transfer, and organizational compliance policies.

## 4. Calendars and external note services

- CalDAV account details, calendars, and event content are exchanged with the server selected by the user.
- When an optional external connector is enabled, CalMee uses user-provided credentials only for the requested import or synchronization operation.
- CalMee does not connect to these services without user configuration and action.

## 5. Usage analytics

The public development build has no official telemetry destination and sends no analytics by default. Anyone distributing a custom build with analytics must use their own endpoint, update this policy, and obtain explicit consent before sending data.

## 6. Permissions

CalMee may request microphone, system audio, file access, and notification permissions. Calendar permission is requested only when On My Mac calendar integration is enabled. Permissions can be revoked at any time in macOS System Settings.

## 7. Deletion and export

Meetings can be deleted in the app. Removing the CalMee application-data directory removes local data. Deletion may be irreversible, and data already synchronized to an external service remains subject to that provider's policies.

## 8. Development status

CalMee is still under development. Do not use it for regulated workloads without backups and an appropriate organizational security review. A formal security reporting channel will be published before general release.
